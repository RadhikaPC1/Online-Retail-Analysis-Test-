# 🛍️ Online Retail Sales Analysis Dashboard (Power BI) – Tata Internship Task 

A **Power BI report** built as **Task 3 of the Tata internship**. It analyses online retail transactions and answers four business questions about revenue trends, top countries, top customers and geographic demand.

---

## 🎯 Project Overview

**Objective:** Use online retail transaction data to answer:

1. How does revenue change month by month through 2011?
2. Which countries generate the most revenue and sell the most units?
3. Who are the top customers by revenue, and how does their spending vary monthly?
4. Where in the world is product demand (quantity) concentrated?

**Structure:** One report page per question (Question 1 → Question 4).
